Why Romit stands out

Shorter code

Shorter code, where the compiler fills in sensible defaults — often one line is a complete program; state intent, not boilerplate.

Reads like a prompt

Plain English-like statements your team and an AI can read in one glance.

No braces or symbols

Indentation only — no braces, brackets, or parentheses in Romit source.

One tool

romit run for scripts; romit check and romit test when you use the optional spec layer; romit build for apps and pages.

Optional checks & tests

Rules, machines, invariants, and test blocks when you want them — not required for every file.

Apps for iPhone and Android

use ui builds reactive apps (state, stacks, controls, navigation, tabs, sheets, saved data) in one index.html that looks native everywhere: Apple style on iPhone and Mac, Material 3 on Android.

Why Romit

Building with AI today means long prompts and large piles of code — hard to review, easy to break.

Romit is a tiny language between a prompt and a program: very little source that humans and models both write and review. Add rules, invariants, and tests only when you want that optional layer.

Getting started in three steps

Step 1

Install

Run the one-line installer for your OS and add ~/.romit/bin to PATH.

Step 2

Write

Create hello.rmt with say "Hello from Romit" — or open the playground.

Step 3

Run & test

romit run hello.rmt for scripts; romit test program.rmt for specs with tests.

A to-do app in 16 lines

Describe the screen for the current data; Romit redraws it when the data changes, like SwiftUI or Jetpack Compose. romit build writes one index.html that runs in any browser and matches the device: Apple style on iPhone, Material 3 on Android. Browsers never read .rmt.

use ui

app Todos
  state
    draft is ""
    todos is list saved

  screen Home "My Todos"
    row
      field "What needs doing?" bind draft
      button "Add" do add draft to todos
        style prominent
        disabled if draft is empty
    list
      for each todo in todos
        text todo
          on delete do remove todo from todos
    caption "{count of todos} to do"
